# First-ML-Avalon.AI-Cohort

This repository collects practice work and learning materials from the Avalon.AI machine learning cohort. It currently focuses on Python fundamentals, object-oriented programming, NumPy, linear algebra, and introductory GPU/CUDA material.

## Repository contents

### Python notebooks

| File | Description |
| --- | --- |
| `Avalon.AI_list_tuple_practice.ipynb` | Exercises on Python list and tuple fundamentals. |
| `Built_in_Exception_Handling.ipynb` | Notes and examples on built-in exceptions, exception flow, and user-defined exceptions. |
| `CUDA.ipynb` | Introductory CUDA compiler and GPU programming examples. |
| `LEGB_RULE.ipynb` | Examples of Python's Local, Enclosing, Global, and Built-in name lookup scopes. |
| `Mastering_numpy.ipynb` | NumPy learning notes and array-focused practice. |
| `Python_in_the_Era.ipynb` | Notes on why learning Python remains useful in an era when AI can generate code. |
| `Regular_Expression_Operations.ipynb` | Practice with regular expressions and text matching operations. |
| `linear_aljebra.ipynb` | Linear algebra examples, including vectors, cosine similarity, and visualizations. |
| `list_and_tuple.ipynb` | Introductory notes and examples for mutable lists and immutable tuples. |
| `prerequistic_oops.ipynb` | Programming prerequisites for OOP, including functions, parameters, recursion, and problem-solving exercises. |
| `python_func_args_practice.ipynb` | Practice with Python function arguments. |
| `python_oops.ipynb` | Notebook exercises and notes on object-oriented programming in Python. |
| `python_revesion.ipynb` | Python revision exercises, including calculator, word-frequency, duplicate-list, menu, and class problems. |

## Working with the materials

The notebooks can be opened in Jupyter Notebook, JupyterLab, or Google Colab. Python scripts can be run with a Python interpreter. Some exercises are works in progress, and notebooks or scripts may require packages beyond the Python standard library.
